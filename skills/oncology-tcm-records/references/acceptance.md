# 病程网页验收与来源

在用户要求测试或修改病程生成器时读取。本文件提供验收方法，没有记录任何已执行测试的结果，也不构成临床合格证明。

## 实际验收

从当前 `123.html` 进入“快速写病程”，使用用户已授权的去标识资料；缺少合适资料时可用明确标注的虚构教学输入测试功能，但不得把教学输入或结果称为真实患者验证。不要通过公开检索、外部语音服务或第三方 API 发送患者资料。

先记录网页版本、测试日期、浏览器与输入资料编号。由实际页面选择患者、记录类型、时间、病种及本次证型，填写或粘贴本次资料，再操作生成。保存输入和真实生成文本后逐项检查；通过函数调用或代码阅读得到的结论只能标为该层检查，不能声称通过了页面流程。

| 场景 | 检查的实际行为 |
| --- | --- |
| 同一组完整资料分别生成四类记录 | 题头与时间正确，四类内容有各自重心；有事实支持的分析确实出现，不仅更换标题。 |
| 缺少今日查体、舌脉、检查或医生计划 | 具体缺项能看见；不自动补正常体征、典型舌脉或新决定；已有资料仍被整理。 |
| 混合既往、昨日、今日及未来计划 | 事实保持时间归属；检查日期与记录日期区分；拟用药、拟复查不写成已经实施。 |
| 症状否定、不确定诊断、检验方法与单位 | 否定范围和不确定性保留；方法、值、单位保持对应；没有未提供的排除结论。 |
| 同一时间有不同检查值或病理/证型冲突 | 两个来源可追溯并提示人工核对；有明确不同日期时能区分病情变化。 |
| 已选证型但四诊不足或不符；自定义证型 | 不套出未提供的典型症状；指出具体依据和不足；匹配不到时如实说明，不套用其他癌种。 |
| 提供已实施治疗、医师调整理由与效果 | 按资料呈现决定、实施、效果及理由；不另造药物、剂量、疗程、复查时间或疗效结论。 |
| 查房医师姓名/职务或实际意见缺失 | 留明待核对，不代签，不编上级医师发言。 |
| 经典开启/关闭，切换病种及证型 | 引文有原文、书名、篇名、链接和本地条目来源；不会被当作肿瘤病理/分期证明；关闭后正文保持可读。 |
| 生成后修改输入、切换患者、返回前次记录 | 草稿与最新输入一致；前次病情和另一患者信息不混入今日事实。 |
| 复制、保存、重开或导出（任务涉及时） | 检查实际内容及所属患者/日期。保存测试可在隔离副本或测试患者执行；保留实际观察，不能仅凭按钮文案认为已保存。 |

每个场景记录：输入编号、操作路径、观察到的输出、原文对照、通过/不通过/未执行及原因。遇到关键错误就保留复现证据，修复后复测受影响场景；不靠字数、标题或固定措辞判断病案质量。

自动化校验只能辅助发现结构、字段或明显文本错误。HTML 静态语法检查、技能 `quick_validate` 和真实浏览器验收分别报告。没有负责医师评阅时，结论限于功能和资料忠实度。

## 保留功能并减少操作

用户当前目标是“功能全保留，减少重复录入和切页”。改动前列出实际可用功能与数据操作，改动后通过同类任务核对；本项目目前包括快速写病程、患者病案工作台、查找与选段、生成病程记录、检查分析、肿瘤分期及中药处方分析。入口名称和布局可以调整，但应能完成原有任务并保持来源核对、修改、保存/导出等已有能力。

- 用同一份明确归属本次记录的资料，走完常见“选患者→录入/粘贴→核对检查及中医资料→生成→修改/保存”路径。记录实际重复填写项与切页次数；与改动前比较时使用相同任务范围和资料。
- 单次输入可供需要该资料的模块使用；仍需医生补充或确认的内容有明确理由，不要求把已提供的主诉、检查、处方或舌脉再抄一遍。未经确认的自动提取结果不变成正式决定。
- 检查手动修正与粘贴内容冲突、修改记录日期、切换患者、返回历史记录时的数据归属；共享输入不应引入其他患者事实或把过去资料冒充今日资料。
- 验证高级选项仍可发现和操作，未识别原文与来源可回看，草稿编辑不因切换视图丢失。折叠内容不应造成必须填写的字段找不到。
- 分别报告已保留的功能、实际少填的项、实际少切的页面与未执行场景。不能用减少页面数量或隐藏字段替代完成任务的证据。

## 写作规范来源

核对日期：2026-10-03。以下文件是文书结构参考，不是肿瘤或中医治疗指南；2010 年文件的存在不证明已完成现行有效性、所有后续规定或本院制度的审查。院内版本、模板和签署流程另行核对。

1. [卫生部关于印发《病历书写基本规范》的通知](https://www.nhc.gov.cn/wjw/c100175/201002/b1bec53d90f243e0861529723f00221a.shtml)：国家卫生健康委员会官网，卫医政发〔2010〕11号；重点查第三条、第二十二条及中医规范另行制定的条款。用于一般事实忠实、病程连续性与记录类型的结构依据，不混用2002试行稿。
2. [中医病历书写基本规范](https://hospital.seu.edu.cn/2023/0304/c29923a435974/page.htm)：东南大学医院全文公开页，2023-03-04发布；页面标注制发机关为卫生部、国家中医药管理局，文号国中医药医政发〔2010〕29号。此链接是医院公布的2010文件全文，不是2023制定的新规范，也不是发文机关的原始发布页。重点查第三条、第九至十条、第十九条（四诊）、第二十三条（病程与理法方药）。

内容使用要点：记录真实可追溯的事实；中医诊断分别呈现病名和证候；日常记录体现当次四诊及既有治法方药变化的理由；查房记录整理真实医师的分析与意见。首次病程、主治首次查房有文书时限要求，按原文及本院制度核对，不能伪造记录时间以满足时限。

## 本地语料与功能来源

项目入口为当前工作区 `123.html`，不要绑定某一固定用户路径。读取 `corpusData` 内条目 ID、`text`、`quote/quotes`，及 `TCM_PROFILES` 的病种、证型、依据提示、病机、治法方向和引文字段；字段会随产品变动，以实际文件为准。语料中的【】是待替换槽位，列举的常见症状不是本例观察。

新增或更换经典出处时按实际读取的原典核验书名、篇名和文字，保留版本/链接和核对状态。本技能不附第三方治疗语料，也不要求安装医学 NLP、LLM SDK 或语音识别组件。
