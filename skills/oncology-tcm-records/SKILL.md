# 中医肿瘤病程辅助

把已提供的患者资料和医师决定整理成可核对的病程草稿，或据此验收病程生成器。沿用用户的网页、语料与医院格式；本项目以用户指定的 `123.html` 或后续版本为入口。技能是给 Codex 的工作指南，不会自行改变离线网页的生成逻辑。

## 先辨明任务

- 起草或核对记录：确认记录类型、记录日期时间及本次资料，按下述规则整理。
- 改进或验收网页：阅读 [references/acceptance.md](references/acceptance.md)，在实际页面操作并检查生成结果。只在用户授权的任务范围内修改产品；加载技能本身不意味着要改网页。
- 医院已有格式或用户给出的合格样例优先用于版式与措辞。制度要求另核对适用版本；本技能不声称通过临床认证。

## 改进网页的取舍

按用户“功能全保留，减少重复录入和切页”的要求推进。先查看当前页面与可用入口，保留病程起草、患者病案工作台、语料查找与选段、检查分析、肿瘤分期及中药处方分析等现有能力；可合并工作流或调整布局，但不能借简化界面删掉功能、来源、核对信息或已有数据。

患者基本信息在同一患者内复用，本次资料尽量一次录入或整段粘贴，再供相关模块使用。共享的是带患者、事件日期与来源的资料，不是未经确认的诊断或模板中的默认事实。不同患者、不同日期的症状、查体、舌脉、处方与计划不能自动沿用。

把常用操作与结果核对放在连贯流程内；少见选项可按需展开，但保持入口可发现。自动提取后的字段要可核对、可修正；原文、未识别内容和手动修改应保留。手填与粘贴资料冲突时明确提示，不能用同步动作静默覆盖。减少操作的效果须在真实页面验证，不靠代码变化或按钮数量宣称改善。

## 事实与时间归属

先给可用的原文片段建立稳定编号，记录来源、原文、事件日期、结果报告日期、记录时间及状态。可用简表或现有网页字段实现，不必另外造数据库。让每项患者事实能回到一个原文位置或用户明确填写的字段；语料模板、教学案例、经典条文不是患者事实。

- 保留病理部位与类型、检测方法、单位、数值、不确定词、否定范围及“患者自述/外院报告”等归属。不把“考虑、待排、未检出、未提供”改成确诊或阴性结论。
- 区分既往、入院时、昨日、本次、计划、已实施和实施后效果。“拟复查”不代表已复查；过去处方不代表今日继续服用。
- 以用户给出的记录日期解释“今日/昨日”。无可靠日期锚点时保留相对日期并标记待核对，不用电脑当前日期替代临床时间。
- 多份记录比较要保留各自日期；“升高、下降、好转、进展、稳定、有效”需有可比数据或医生明确判断。癌种、病理、分期、疗程和体能评分仅写已提供的结论及来源，不从单一检查自行推断。
- 同一事件存在矛盾值、日期、部位、证型或诊断时，同时列出来源并标记待核对，不擅自选值、求平均或把其中一项藏掉。能确认是时间变化的资料不误判为矛盾。
- 缺失内容写具体缺项。不要用“无特殊”“一般可”“未见异常”“继续原方案”填空；没有提供查体、舌脉或医师意见就不能写已查、已见、已决定。

## 四类记录的重心

以下是结构参考，不授权生成新的诊疗决定。治疗、处方、检查安排、调护和复评时间据医师已提供的意见记录；未提供的决定留作待补。

| 记录类型 | 应体现的内容 |
| --- | --- |
| 首次病程记录 | 病例特点；中西医诊断及已提供的依据、鉴别分析；医师诊疗计划。把主诉、现病史、四诊、查体和检查中的实际证据归纳到相应问题。 |
| 日常病程记录 | 本次病情及证候变化；重要检查、治疗实施与反馈；已有治疗调整及其理由；医生要求的后续观察。没有新资料时不把前次观察冒充今日观察。 |
| 主治中医师查房记录 | 实际查房时间、医师姓名和职务；补充病史体征；医生对诊断、鉴别、理法方药及疗效的分析和下一步意见。首次与日常查房按实际场景区分。 |
| 主任中医师查房记录 | 实际查房医师信息；对关键问题、病情与证候演变、理法方药的综合分析；实际提出的诊疗意见及落实情况。没有上级医师意见时不伪造“主任认为”。 |

四类草稿应有各自的分析内容，不能只换标题，也不能在已有资料足够时输出整段空壳。资料不足仍整理有来源的内容，并明确区分“已知事实”“可供医生核对的解释”“待补的医生决定”。医师信息仅作为核对字段，不代签、代证实实际查房或补写已发生的行为。

## 四诊、证型、病机与经典

- 使用本次实际四诊；缺少舌、脉时分别说明，不套入证型常见舌脉。用户选择了证型只代表输入的证型，不代表已证明该证型。
- 将已经确认的中医病名、证型与具体症状、舌脉逐项对应，整理病位、病性和相互关系。依据不足或不相符时指出哪项支持、哪项待核对；不要仅凭癌种或久病自动确定证型。
- 病机解释与既有治法、方药分析应形成可理解的关联。仅整理已给处方的药名、剂量、用法及医师方义；来源无明确对应时标记方义待核对，不自行加减药、换方、定量或决定停续治疗。
- 辨证鉴别可整理医生原有意见，或从本地语料提取相近证型的鉴别要点作为资料核对提示，清楚标明尚待医生判断。不要把教材鉴别要点写成患者已出现的症状或新的排除结论。
- 先查本项目 `123.html` 的 `corpusData`、`TCM_PROFILES` 及条目的 `quote/quotes`，保留条目 ID、书名、篇名和链接。大段压缩 HTML 用小范围提取读取，避免一次倾倒全文。
- 本地经典引文属于已收录资料，不能据此声称刚刚核验原典。直接引文需能核对文本与篇名；有疑义则用注明来源的转述或待核实标记。只在任务需要时查原典，不上传患者资料来检索。
- 经典用于解释相关中医病机，不用于证明现代肿瘤诊断、分期、疗效或处方适应证。不引入特定名医人设、治疗风格或教材外经验替代本项目既有语料。

## 交付与核对

正文使用临床病程语言。原典校订、生成规则、模型能力、安全解释及“不能自动补写”“未采纳原文”等编辑说明放入核对区，不混入病程正文；缺失只留具体待补项。

给出可编辑的病程草稿，随后列出具体待补项、矛盾项及来源索引；医院正文格式不宜放来源编号时，把索引留在独立核对区。复核每个数值、否定、日期和行为状态，以及症状—证型—病机的对应是否有据。

最终说明资料覆盖程度与实际检验结果；结构完整不等于事实完整、诊疗合理或临床合格。草稿须由负责医师核对、补充并按院内流程签署。不要以一条笼统免责声明代替具体缺项与问题说明。
